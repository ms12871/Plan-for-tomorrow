Plan For Tomorrow — Productivity Web App
A clean, single-screen productivity launchpad built with vanilla HTML, CSS, and modern JavaScript. Specifically designed for evening planning to eliminate morning decision fatigue.
Features
-	The One Thing Spotlight: Forces focus on a single high-leverage objective.
-	Top 3 Secondary Tasks: Keeps non-primary commitments bounded to 3 slots.
-	6 AM – 10 PM Time-Blocking Grid: Hourly breakdown with a 1-click suggested workflow.
-	Evening Launchpad Checklist: Bedtime prep checklist to safeguard sleep and morning momentum.
-	Micro-Tasks & Brain Dump: Offload late-night thoughts and convert bullet lines into quick wins with one click.
-	Local Persistence & Export: Automatically stores state to browser localStorage, prints cleanly to PDF, and copies structured Markdown.
Deploying via VS Code & GitHub Pages
1.	Open this folder in VS Code.
2.	Run git init, git add ., and git commit -m "Initial commit".
3.	Create a new GitHub repository and push your branch:

git remote add origin https://github.com/<your-username>/<repo-name>.git

git branch -M main

git push -u origin main

4.	In GitHub, navigate to Settings > Pages and set source to the main branch.
